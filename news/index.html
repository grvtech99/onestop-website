How admin publishing works

  1. Deploy the included Apps Script as a Web App.
  2. Paste its URL and matching admin key above.
  3. Use Publish / Sync to send this browser's settings and articles to the server.
  4. On the public site, set the same Web App URL in the script's published configuration or embed the URL in this HTML as instructed in README.

Important: Browser-only edits are local to this browser until synced. Apps Script is a simple JSON backend; protect the admin key and restrict who can edit/deploy the script.
