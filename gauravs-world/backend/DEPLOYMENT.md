# Gaurav's World — Secure Admin Deployment

The secure Admin is now an Apps Script HTML app. It uses `google.script.run`, so the browser does not need a public REST/CORS connection and no GitHub/OpenAI secret is placed in the page.

## Files

- `Code.gs` — authenticated backend, GitHub read/write, manual image upload, draft/publish/unpublish/delete, optional AI text draft.
- `Admin.html` — admin UI served by Apps Script.

## Script Properties

Set these in Apps Script → Project Settings → Script Properties:

| Property | Value / purpose |
|---|---|
| `ADMIN_EMAIL` | Your exact Google account email, lowercase is normalized |
| `GITHUB_TOKEN` | GitHub token with minimum required Contents write permission |
| `GITHUB_OWNER` | `grvtech99` |
| `GITHUB_REPO` | `onestop-website` |
| `GITHUB_BRANCH` | `main` |
| `OPENAI_API_KEY` | Optional; used only when you press Generate AI Draft (manual images are not generated by AI) |
| `OPENAI_MODEL` | Optional; defaults to `gpt-4.1-mini` |

Never put tokens or keys into HTML, GitHub source, screenshots, or chat.

## Deploy

1. Open the Apps Script project behind the supplied `/exec` URL.
2. Replace `Code.gs` with this repository version.
3. Add a new HTML file named exactly `Admin` and paste `Admin.html` into it.
4. Set the Script Properties above.
5. Deploy → Manage deployments → Edit the Web app → create/select the new version.
6. Execute as: **Me** (the account that owns the GitHub token and backend).
7. Access: use the narrowest setting that allows the intended admin Google account. Do not make this privileged backend anonymous/public.
8. Open the same `/exec` URL while signed in to the configured `ADMIN_EMAIL` account.

## Admin capabilities

- Create a new article manually.
- Save draft to `gauravs-world/data/drafts/<slug>.json`.
- Upload cover image manually to `gauravs-world/images/<filename>` (PNG/JPG/WEBP, max 2 MB).
- Publish only after pressing the Publish button.
- Unpublish removes the article from the published manifest and repository article JSON.
- Delete draft.
- Load published articles and edit them.
- Optional AI text drafting remains available, but there is **no AI image generation** anywhere in this Admin implementation.

## Security model

Every server-side operation calls `assertAdmin_()`, which compares the signed-in Google account returned by `Session.getActiveUser().getEmail()` with `ADMIN_EMAIL`. GitHub credentials remain in Script Properties. Client-side JavaScript never receives the GitHub token or OpenAI key.

If Apps Script cannot provide the active user's email in the selected deployment/account context, access is denied. Do not solve that by making the app public or adding a client-side password.

## Important

A GitHub commit does not update an already-deployed Apps Script version. After changing `Code.gs` or `Admin.html`, update the deployment and test the `/exec` URL. Test login, list, image upload, save draft, and a non-critical test publish before using production articles.
