# Gaurav's World — Images

Store article cover images and generated illustrations in this folder.

## Naming convention
- Use lowercase kebab-case filenames matching the article ID, e.g. `computer-basics.webp`.
- Prefer optimized WebP or AVIF; keep images responsive and reasonably small.
- Use descriptive alt text in the article metadata.
- Do not commit private, copyrighted, or unlicensed images.

For GitHub Pages, reference an image with a relative path such as `images/computer-basics.webp`.
