3. Recommended Audit Sequence

  1. Source Review Center — check changed/failed sources.
  2. Review Queue — identify items waiting for verification.
  3. Verify official notice — title, vacancy, dates, eligibility, fee, age, selection, notice PDF and application URL.
  4. Verified Drafts — confirm the verified record is correct.
  5. Publication Center — create the publication PR through GitHub Actions.
  6. GitHub Pull Request — review the generated publication file and approve/merge only when correct.
  7. Public Job Updates — confirm the final published entry appears correctly.
