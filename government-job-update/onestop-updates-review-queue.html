Controlled Lifecycle

  1. Pending: official source changed and needs human verification.
  2. In Review: a dedicated GitHub review issue has been created.
  3. Verified: repository owner confirmed the actual official notice and supplied a structured draft.
  4. Rejected: the change was irrelevant, duplicated or could not be verified.
  5. Publication: a verified draft still requires a separate publication PR and explicit owner approval before public data changes.
✔ Verified and rejected states are now persisted in the queue. Public Job Update data remains isolated until the final approved publication workflow runs.

The static site never stores GitHub credentials. Review and publication actions are performed through authenticated GitHub workflows.
